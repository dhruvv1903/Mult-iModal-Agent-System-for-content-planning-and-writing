AI Multi-Agent Content Generator

This project is a multi-agent AI content generation system built using CrewAI and Google Gemini.

The system uses three AI agents:

1. Content Planner – Creates the content plan, identifies the target audience, trends, SEO keywords, and relevant resources.

2. Content Writer – Uses the content plan to generate a structured and engaging blog post.

3. Editor – Reviews and improves the generated blog for grammar, style, and overall quality.

The workflow is:

Topic → Content Planner → Content Writer → Editor → Final Blog

Tech Stack:
Python
CrewAI
Google Gemini 3.6 Flash
uv
python-dotenv

The project demonstrates LLM integration, AI agents, task orchestration, prompt engineering, and multi-agent workflows.
